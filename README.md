# AI Security for Students 🎓🤖

A free, no-fluff starting guide for students who want to learn **AI security** — how attacks on AI systems work, how to defend them, and what to actually study first. Built from free resources only. No paid courses needed.

> Made for cyber students and self-learners. Bookmark it, study one section per week, finish in ~2 months.

---

## 📍 Why this matters

Companies are adding AI to everything, but very few people know how to secure it. That gap = your opportunity. AI security blends classic cybersecurity with a new attack surface: the model itself, its data, and its users.

## 🗺️ Learning path (in order)

**1. Foundations (2–3 weeks)**
* Networking + Linux basics — https://linuxjourney.com
* Web basics — https://developer.mozilla.org/en-US/docs/Learn
* Core security concepts — https://tryhackme.com/path/outline/presecurity (free tier)

**2. AI basics (2–3 weeks)**
* What LLMs actually are — https://www.linkedin.com/learning/paths/… → better: https://huggingface.co/learn/nlp-course/chapter1/1
* Prompting & how models fail — https://learn.deeplearning.io/courses (free short courses)

**3. AI attacks (3–4 weeks)**
* OWASP Top 10 for LLM Applications — https://genai.owasp.org
* MITRE ATLAS (adversarial ML tactics) — https://atlas.mitre.org
* Prompt injection explained — https://portswigger.net/daily-swig/prompt-injection
* Practice prompts safely — https://glenwehrly.gosecure.ai/prompt-injection/

**4. Defense (3–4 weeks)**
* OWASP Agentic AI / LLM security guidance — https://genai.owasp.org/llm-top-10/
* NIST AI Risk Management Framework — https://www.nist.gov/itl/ai-risk-management-framework
* AI red-teaming basics — https://aival.uncharted.ai / https://crfm.stanford.edu/aisb/

**5. Hands-on practice (ongoing)**
* Free security labs — https://tryhackme.com and https://www.hackthebox.com (free tiers)
* Web security academy (free) — https://portswigger.net/web-security
* Build: secure a small chatbot, log prompts, add input filtering, document it

## 🧰 Free tools to learn

* **Garak** — LLM vulnerability scanner: https://github.com/NVIDIA/garak
* **PyRIT** — Microsoft AI red-teaming framework: https://github.com/Azure/PyRIT
* **Promptfoo** — test LLM apps for injection: https://www.promptfoo.dev
* **ModelScan** — scan ML models for malicious code: https://github.com/protectai/modelscan

## ✅ How to use this guide

1. Don't skip step 1 — AI security still runs on classic security fundamentals
2. Study 1–2 hours daily, build something each week, push it to GitHub
3. Write short notes on what you learn — teaching is the fastest way to remember
